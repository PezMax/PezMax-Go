## 项目简介

**PezMax 智能资料助手｜Python、LangGraph、Pydantic、FastAPI、MCP、SQLite、Electron、Vue 3、Ant Design Vue、Go**

为资料管理桌面客户端开发独立 LangGraph 智能体模块，支持用户自带模型 API Key，实现自然语言目录检索、可确认的上传分类建议及 PDF/EPUB 阅读问答、摘要、提纲和证据定位。

独立服务模式增加 FastAPI、官方 MCP SDK 2.x 只读工具与资源，以及跨文档 RAG。文档显式导入 SQLite；中文/英文 BM25 与可选 BYOK 向量通过 RRF 融合，跨文档引用须通过文档、片段、位置和原文校验。0.3 已接入 Ant Design Vue 桌面知识库，支持导入/删除、检索、问答与索引原文查看；桌面使用 stdio 复用核心，没有自动启动 HTTP/MCP 服务。实现接入不等于公开发行，发布情况另行说明。

## 可用于简历的描述

- 基于 LangGraph StateGraph 实现资料检索 Agent，编排模型与白名单工具的条件循环，支持多轮追问、目录分页与结果去重，设置5轮模型/8次检索预算；模型元数据和本地资源操作对象分离。
- 构建 PDF/EPUB 所选内容阅读链路，采用 Pydantic 严格结构校验和连续原文/位置双校验，以条件边实现最多一次纠正；保留有效回答，证据不足时拒答，支持页码与分节引用跳转。
- 设计 Electron–Python stdio 边界和 BYOK 凭据管理，密钥使用主进程内存及可选操作系统加密，平台令牌不进入模型与图状态；实现取消、超时、账号隔离和迟到结果防护。
- 建立不采集正文的节点计时与调用计数，以及版本化合成用例和三种处理方式的离线对照评测，覆盖2种格式×3种任务×10种输出场景；通过源码/冻结运行时集成链路验证发布一致性。
- 将应用层复用于 stdio 和 FastAPI，使用稳定认证身份隔离本地文档、限定模型接口及请求预算；基于官方 MCP SDK 2.x 提供只读检索与原文资源，支持外部 Agent 宿主接入。
- 构建 SQLite 持久化文档检索：按位置分块和内容哈希去重，中文/英文 BM25 与可选 BYOK embedding 的精确余弦检索经 RRF 融合；建立文档级 Recall@3 / MRR@3 评测入口，真实 embedding 效果须实测后再写数字。
- 将 RAG 接入 Ant Design Vue 桌面知识库：系统文件选择器控制导入、独立对话/Embedding BYOK 配置、本地关键词检索与可选计费混合检索、逐条引用原文查看；沿用 stdio worker 的超时、取消、账号过滤和迟到结果防护。
- 将业务数据库中的平台资料与电子书接入 RAG：通过 Go 来源目录与版本核验接口增量同步正文，建立业务 ID 与索引片段的关联；检索前和生成后核验上架状态，支持 PDF 页码、EPUB 章节引用回跳。当前为最多200篇的客户端索引缓存，尚非全站共享检索。

## 五分钟演示路线

1. 打开模型设置，说明用户提供 Key、可选 OS 加密及连接测试。用专用演示配置，不展示真实密钥。
2. 输入目录检索需求，展示真实资源卡片、条件筛选和追问；说明工具/轮次预算与真实结果投影。
3. 用明确标注的合成数学/软件文档演示选页/分节、本地提取、摘要/提纲、原文引用与跳转；说明抽样覆盖限制。
4. 用上传文件名演示建议生成、用户逐项选择、手动编辑冲突处理；强调不会自动提交。
5. 运行 `npm run agent:eval`，展示结果及错位置→一次纠正的节点路径；说明脚本评测与真实模型评测的区别。

可将第4步替换为“我的知识库”导入合成软件文档、免费本地检索、问答与引用原文查看，再说明为何对话与向量模型的 Key 分开配置。服务岗位还可运行 `examples/service_demo.py` 演示 REST，使用外部 MCP 客户端演示工具与资源。需要按服务文档配置身份和 BYOK，不在录像中展示 Key。

## 面试时应能解释

| 常见问题 | 对应设计与代码 |
| --- | --- |
| 为什么使用 LangGraph？ | 显式状态、条件边、可界定的循环和预算；`graph.py` / `reading.py` |
| 与调用一个聊天接口有什么区别？ | 白名单工具、平台结果映射、结构验证、引文验证、条件纠正、取消/隔离和可复现评测 |
| 引用核验能解决幻觉吗？ | 能阻止不存在或错位置的引用，不能证明语义推论正确；仍需真实模型与人工评测 |
| 为什么没有独立向量数据库？ | 原阅读面板只处理所选页/节；桌面与服务的知识库用 SQLite 保存向量并做有界精确扫描，适合小型本地资料库。扩容前需测召回、吞吐、索引生命周期与 ANN 收益 |
| MCP 和 API 有什么不同？ | FastAPI 暴露带认证的业务接口；MCP 由外部宿主启动 stdio 服务，用标准 tools/resources 暴露只读检索和原文。共享服务，不重复实现检索算法 |
| 为什么不直接接入托管 tracing/checkpoint？ | BYOK 客户端默认不应额外导出正文；本机数值诊断足以解释当前短任务，持久化恢复尚未实现 |
| 如何防止无止境自纠正？ | 一次纠正、原证据不变、图递归限制和总处理超时；模型预算可由诊断与评测复核 |
| 如何证明有效？ | 合成契约用例、三种处理方式对照、源码与冻结集成；真实用户和真实模型效果单独测量 |

不要写“消除幻觉”“准确率提升XX%”“生产级大规模检索”“支持多智能体/断点恢复”等仓库未实现或未测得的结论。MCP、可选向量 RAG 与桌面知识库均有对应实现，但不能据此宣称真实模型效果提升、公开发布或云生产验证完成。
