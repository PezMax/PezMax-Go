## 离线评测结果的含义

数据集：`PezMax-Agent/evals/reading-cases.json` v1，SHA256（UTF-8、统一为LF换行）：`d158836f57eadd1ac8815640d07187f79a6c5f7efcdb125e56f4bb1fdc185ebf`。生成的报告包含数据集版本和该摘要，便于跨平台复现。

- 10种场景 × PDF/EPUB × 问答/摘要/提纲 = 60个案例，全部达到预设答案数和调用预算。
- 未经验证的首答包含36条无效候选；仅校验与带纠正两种方式均未释放无效候选。
- 18个预设可恢复案例在一次纠正后返回符合契约的答案；总计90次脚本模型调用，单案例最多2次，空文字不调用模型。
- 这些数字只验证**编排、结构和引文契约**，不衡量真实模型语义准确率、线上延迟、成本或用户体验提升。没有进行真实模型规模评测，也没有人工标注的语义蕴含评价。

## 客户端实测与剩余范围

在已登录的本地隔离客户端中，通过 Windows computer-use 操作确认：打开合成 PDF、打开阅读助手、本机提取所选页、切换内容摘要、获得带物理页码和连续原文引用的摘要。未读取或导出用户 Key，未操作登录/验证码，也未使用真实用户文档。

PDF 原生预览仍缓存了曾被替换的同名合成文件旧版（1页），而提取器 `no-cache` 读取新版（3页）。因此这次试用不能证明预览正文与引用完全一致；后续完整客户端回归应使用新的文件 URL 或新本地文件。引用按钮当时在可视区域外，随后检测到用户窗口输入，本轮未继续争用界面，**未确认完整 PDF 引用跳转，也未执行完整 EPUB 原生界面流程**。对应契约、SFC 发出的定位事件、真实 epub.js 提取和两种运行时链路已经自动验证。

Windows 冻结构建提示缺少可选 `tzdata` 隐式导入；当前任务及独立运行时集成均通过，尚未测试 IANA 时区数据相关能力。npm 镜像配置和 Node VM/本地存储实验特性存在工具链提示，不影响本轮检查退出状态。
