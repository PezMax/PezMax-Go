`npm run test:agent-integration` 统一执行原2项和新增2项；此次分别运行两个文件/模式验证，各项均通过。桌面结果来自当前共享工作区，含用户原有未提交改动，不等同于干净检出验证；这些无关改动不纳入本次提交。

合成文件明确标注为软件队列示例。检索与解析使用真实代码，生成和 embedding 使用本机脚本服务；不代表真实服务商兼容性、语义检索收益、生成准确率、费用或线上性能。没有读取用户保存的 Key 或私人文档，没有调用计费模型。真实登录/验证码与系统文件选择器没有自动操作；SFC 测试执行组件事件与生命周期，生产构建校验模板及依赖，不能称作人工桌面点击验收或浏览器视觉验收。

已通过源码审查补齐工作区 flex 布局，并在移除 Embedding Key 时退回关键词模式。模型输出仍需用户核对语义，原文引用校验只证明位置和连续引用存在。

文档正文与可选向量会持久化到明文 SQLite，逻辑删除不保证物理擦除。当前引用打开索引原文抽屉，不回到原始文件；不支持 OCR、reranker、ANN、token 流式输出或持久任务恢复。
