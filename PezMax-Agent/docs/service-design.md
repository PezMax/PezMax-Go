# Agent 服务化与文档检索设计

## 可行性与交付边界

现有 Python 模块已经把模型适配、目录检索、LangGraph 图和 stdio 协议分开。FastAPI 与 MCP 可以作为新增适配层，共享知识库服务，而无需替换 Electron 已验证的 stdio 调用链。服务依赖作为 `service` extra 安装，不让桌面冻结入口主动导入 Web/MCP 模块。

当前阅读仅对用户所选的少量页/分节筛选片段，没有持久化全文索引。RAG 因而有明确价值：一次导入文档，跨文档提问，再按文档、位置、片段核验引用。采用适合本地小型知识库的 SQLite，而非先引入向量数据库集群。

本期实现：

- PDF、EPUB、UTF-8 文本/Markdown 的显式导入；也接受已有提取器输出的带位置文本。
- 按页/分节分块，内容哈希去重，SQLite 事务保存、列表及删除；按服务认证身份隔离。
- 中文单字/双字与英文词项 BM25；可选用户自带 embedding 接口，以余弦相似度检索，并用 RRF 融合。模型指纹和向量维度不匹配时报错，不静默混用向量。
- LangGraph 检索、生成、验证与最多一次纠正；文档 ID、片段 ID、位置、连续原文共同核验。上下文最多六段，正文不进入诊断。
- FastAPI 的认证、容量和请求体限制、调用超时及 OpenAPI；现有上传/阅读/目录任务与新知识库问答复用同一模型适配层。
- 官方 MCP SDK 的只读工具和资源，复用相同索引与查询实现；MCP 进程的知识库身份由宿主配置，模型不能通过工具参数切换用户或指定文件路径。

不在本期范围：自动采集平台全部文档、OCR、云多租户产品化运维、分布式向量数据库、持久任务恢复、语义正确率保证。API/MCP 是独立入口，桌面现有阅读面板仍使用原 stdio；本期不宣称桌面已经接入知识库管理 UI。

## 数据与费用边界

索引包含用户主动导入的正文及可选向量，会落在本机 SQLite，按用户删除。认证令牌由部署者配置；模型/embedding Key 仅用于本次请求，不存入数据库或图状态。开启向量索引时会把文档分块发给指定 embedding 服务，查询时发送问题；生成时仅发送检索片段。关键词模式不调用 embedding 服务。

HTTP 模型地址使用部署者配置的精确 base URL 白名单；目录地址由部署者配置，调用者只提供平台令牌。服务器不提供任意 URL 抓取或任意路径读取接口。默认只监听回环地址。MCP 只读检索与取证，不提供删除或导入工具。

## 验证目标

采用合成软件/数学资料验证导入、重启持久化、去重删除、中文与英文召回、混合排序、向量指纹、用户隔离、跨文档引文核验及有界纠正；通过 ASGI 客户端验证真实 API，并通过官方 MCP 客户端验证 stdio 握手、工具和资源。报告区分脚本 embedding/模型测试与真实模型效果，不虚构线上指标。
